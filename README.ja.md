# Crochet Weaver

**[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)**

Crochet Weaver は、Obsidian のノート内でテキストの編み図パターンをかぎ針編みチャートに変換するプラグインです。すべてローカルの Markdown コードブロック内で動作し、ネットワーク通信は一切行いません。

## 主な機能

- `crochet` コードブロックを、テーマに合わせた SVG 編み図チャートとして描画します。
- 往復編み・同心円の輪編み・連続スパイラルの 3 種類のレイアウトに対応します。
- くさり編み、細編み、中長編み、長編み、長々編み、引き抜き編み、増し目、減らし目、パフ編み、ポップコーン編み、うね編み（前後の引き上げ編み）など、一般的な編み目記号を内蔵しています。
- 段・周単位の `blo`／`flo` マーカーと、輪の作り目（わの作り目・くさり編みの輪）に対応します。
- 同心円の輪編みチャートで、次の周の最初の目に色を変更できるマーカーを表示します。
- `crochet-tool` ブロックは、目数・進捗コントロール・段ごとの目数カウンターを備えた読みやすいチェックリストとして描画されます。
- **進捗ツールまたは読み取り専用の編み図テキストを、`crochet` チャートの隣に直接埋め込めます**（`tool: on` / `text: on`）。同じパターンを 2 つのコードブロックに書く必要はありません。
- **進捗ツールを埋め込んだ場合、チャート上に現在の位置（現在の周と次の目）をリアルタイムで強調表示します**。色は設定で変更できます。
- 進捗はすべてプラグインのデータファイルにローカル保存されます。
- 完全な多言語 UI：英語、繁体字中国語、簡体字中国語、日本語。

## クイックスタート

ノートに `crochet` コードブロックを追加します：

```crochet
---
type: round
scale: 1.25
highlight: on
---
R1: 6 sc in MR
R2: [sc, inc] x 6
R3: [2 sc, inc] x 6, sl st
```

### チャート + 進捗ツールを 1 つのソースで

`tool: on` を追加すると、インタラクティブな進捗ツール（段リスト・目数カウンター）がチャートの隣に埋め込まれます。別途 `crochet-tool` ブロックは不要です：

```crochet
---
id: coaster-small
type: round
tool: on
---
R1: 6 sc in MR
R2: [sc, inc] x 6
R3: [2 sc, inc] x 6, sl st
```

進捗管理はいらないので、チャートの隣にシンプルな略記リストだけ表示したい場合は `text: on` を使います：

```crochet
---
type: round
text: on
---
R1: 6 sc in MR
R2: [sc, inc] x 6
```

チャートなしでチェックリストだけが欲しい場合は、これまで通り独立した `crochet-tool` ブロックも使えます：

```crochet-tool
---
id: coaster-small
type: round
---
R1: 6 sc in MR
R2: [sc, inc] x 6
R3: [2 sc, inc] x 6, sl st
```

パターンのテキストを編集しても進捗を保持したい場合は、明示的に `id` を設定してください。`id` を省略すると、Crochet Weaver はコードブロックの内容からローカルハッシュを生成するため、ブロックの内容を編集すると進捗がリセットされることがあります。

## パターン構文

### Frontmatter

`crochet` ブロックの先頭には、シンプルな YAML 風の frontmatter を追加できます：

```yaml
---
type: flat | round | spiral
id: optional-progress-id
scale: 1.5
stroke: 2
spacing: 40
highlight: on
rotation: smart | all | none
tool: on | off
text: on | off
position: right | left | below
---
```

デフォルトではプラグインのグローバル設定が使われます。frontmatter に有効な値があれば、そのチャートに限りグローバル設定を上書きします。無効な値の場合はグローバル設定にフォールバックします。`tool`・`text`・`position` も同様に、それぞれのグローバルな既定値を持ち、上書きできます（詳細は「設定」を参照）。`showNextRoundMarker` とそのマーカー色はグローバル設定のみで、frontmatter による上書きはできません。

### 段（Row）

段のラベルはどちらの書き方でも構いません：

```crochet
R1: 10 ch
Row 2: sc, hdc, dc
```

対応している段修飾子：

```crochet
R1: blo, 6 sc in MR
R2: flo, 6 sc in ch ring
```

- `blo`：その段・周全体を後ろ半目のみで編むことを示します。
- `flo`：その段・周全体を手前半目のみで編むことを示します。
- `in MR`：輪編み・スパイラルチャートに、わの作り目の中心アンカーを追加します。
- `in ch ring`：くさり編みの輪の中心アンカーを追加します。

### 編み目

対応している編み目名：

- `ch`（くさり編み）
- `sc`（細編み）
- `hdc`（中長編み）
- `dc`（長編み）
- `tr`（長々編み）
- `dtr`（三巻き長編み）
- `sl st`（引き抜き編み）
- `fpdc`（表引き上げ長編み）
- `bpdc`（裏引き上げ長編み）
- `bobble`（パフ編み）
- `popcorn`（ポップコーン編み）
- `inc`（増し目）
- `dec`（減らし目）
- `MR`（わの作り目）

数量の接頭辞に対応しています：

```crochet
R1: 10 ch, 6 sc
```

繰り返しは角括弧を使います：

```crochet
R2: [sc, inc] x 6
```

グループは丸括弧を使い、1 つの目の位置から扇状に展開されます：

```crochet
R3: (dc, ch, dc), sc
```

## チャートの種類

### 往復編み（Flat）

`type: flat` は各段を左右交互に往復するレイアウトで描画します。

```crochet
---
type: flat
---
R1: 10 ch
R2: 10 sc
R3: 10 dc
```

### 同心円の輪編み（Round）

`type: round` は各段を同心円状の周として描画します。段の末尾の `sl st` は引き抜きとして扱われ、その周の目数間隔の計算からは除外されます。

```crochet
---
type: round
---
R1: 6 sc in MR
R2: [sc, inc] x 6, sl st
```

### 連続スパイラル（Spiral）

`type: spiral` はすべての段を 1 本の連続したスパイラルに沿って描画します。

```crochet
---
type: spiral
---
R1: 6 sc in MR
R2: [sc, inc] x 6
R3: [2 sc, inc] x 6
```

## 進捗ツールや編み図テキストの埋め込み

`crochet` ブロックの `tool`／`text` frontmatter キー（またはそれに対応するグローバル設定）を使うと、チャート自身に進捗パネルを持たせることができ、パターンを一度書くだけで済みます：

- `tool: on` — 完全なインタラクティブ進捗ツール（段リスト、進捗バー、`+1`／`−1`／リセット付きの段ごとの目数カウンター、前の周／現在の周を完了／リセットのコントロール）をチャートの隣に埋め込みます。
- `text: on` — 読み取り専用の略記リスト（ラベル、正規化された編み目、目数）を埋め込みます。進捗管理やボタンはありません。図の隣に略記だけ表示したい場合に便利です。
- 両方が有効な場合は `tool` が優先されます（`text` が表示する内容はすべて含まれているためです）。
- `position: right | left | below` で、パネルをチャートに対してどこに配置するかを指定します。`right`（既定）と `left` は横並びで、幅が狭い場合は自動的に縦積みレイアウトに折り返されます。`below` は常に縦積みです。

## 進捗ツール

埋め込み（`tool: on`）でも独立した `crochet-tool` ブロックでも、進捗ツールは 2 つの粒度で進捗を管理します：

- **段・周の進捗** — 段をクリックするとその段にジャンプします。前の周／現在の周を完了／リセットのボタンも使えます。セグメント表示のバーで、完了した段数がひと目で分かります。
- **目数カウンター** — 現在の段について、実際に編み目を 1 目編むたびに `+1` をタップします。その段の総目数に達すると自動的にその段が完了扱いになり、カウンターは 0 にリセットされます。そのため、段の境目を気にせず `+1` をタップし続けられます。`−1` は数え間違いの修正に、リセットボタンは段の進捗には影響を与えずに現在の段の目数だけをクリアするのに使えます。前の周に戻る・現在の周を完了する・リセットする・別の段をクリックする、といった操作を行うと、新しい現在の段の目数カウンターは 0 にリセットされます。

進捗ツールがチャートと同じブロックに埋め込まれている場合（`tool: on`）、チャートは現在の位置をリアルタイムで強調表示します。現在の段は薄い色で、次に編むべき正確な目にはより強い強調表示が付き、どちらも「**チャートの現在位置マーカー色**」の設定で指定した色が使われます。独立した `crochet-tool` ブロックや `text: on` パネルには対応するチャートがないため、この強調表示は行われません。

## 設定

プラグインの設定タブから、以下のグローバルな既定値を設定できます：

- **言語**：Obsidian に合わせるか、英語・繁体字中国語・簡体字中国語・日本語から選択します。
- **チャートの拡大率**：チャートの表示倍率です。
- **記号の線幅**：編み目記号の線幅です。
- **輪の間隔**：輪編み／スパイラルの各輪の間隔です。
- **増し目と減らし目を強調**：`inc` と `dec` をアクセント色で表示します。
- **次の周のマーカーを表示**：同心円の輪編みチャートで、次の周の最初の編み目位置にマーカーを表示します。
- **次の周のマーカーの色**：このマーカーに使う色です。
- **チャートの現在位置マーカー色**：チャートに進捗ツールが埋め込まれているとき、現在の周・目を強調する色です。
- **進捗ツールを既定で表示**：すべての `crochet` チャートに進捗ツールを既定で埋め込みます。`tool: on/off` で個別に上書きできます。
- **編み図テキストを既定で表示**：すべての `crochet` チャートに読み取り専用の編み図テキストを既定で埋め込みます。`text: on/off` で個別に上書きできます。
- **パネルの位置**：埋め込まれたツールまたはテキストパネルの既定位置（右／左／下）です。`position:` で個別に上書きできます。
- **輪編み記号の回転**：輪編み／スパイラルでの記号回転方式です（`smart`、`all`、`none`）。

「個別に上書きできます」と記載のある設定は、対応する frontmatter キー（`scale`、`stroke`、`spacing`、`highlight`、`rotation`、`tool`、`text`、`position`）で 1 枚のチャートごとに上書きできます。`showNextRoundMarker` と 2 つのマーカー色はグローバル設定のみです。

## 安全上の制限

Crochet Weaver は、レイアウトを展開する前に解析済みのチャートを検証します。段数・目数・繰り返し回数・入れ子の深さ・総描画目数が極端に多い場合は、Obsidian のプレビューがフリーズするのを防ぐため、インライン表示のエラーとして処理を拒否します。

現在の制限：

- 最大段数：200 段
- 目数の最大接頭辞：1000
- 最大繰り返し回数：500 回
- 最大総描画目数：5000 目
- 最大入れ子の深さ：8 階層

## プライバシー

Crochet Weaver は Obsidian 内で完全にローカルに動作します。

- テレメトリなし。
- ネットワーク通信なし。
- Vault 全体のスキャンなし。
- パターンのテキストは、描画対象のコードブロックからのみ解析されます。
- 進捗（段の進捗と目数）は、プラグインの `data.json` ファイルにローカル保存されます。

## 開発

依存関係のインストール：

```bash
npm install
```

テストの実行：

```bash
npm test
```

プラグインのビルド：

```bash
npm run build
```

Lint の実行：

```bash
npm run lint
```

パーサーは `src/grammar.peggy` から `src/parser.ts` に生成されます。`src/parser.ts` を手動で編集しないでください。

### AI を使ったパターン作成

AI アシスタントに編み図パターンを Crochet Weaver 構文へ変換してもらいたい場合は、そのために書かれた自己完結型のリファレンス [`docs/ai-pattern-authoring.md`](docs/ai-pattern-authoring.md) を渡してください。すぐに使える Claude Code スキルも用意されています：[`.claude/skills/crochet-weaver-pattern/`](.claude/skills/crochet-weaver-pattern/)。

## 手動インストール

プラグインをビルドし、以下のファイルを Vault のプラグインフォルダーにコピーします：

```text
<Vault>/.obsidian/plugins/crochet-weaver/
  manifest.json
  main.js
  styles.css
```

Obsidian を再読み込みし、**設定 → コミュニティプラグイン**で **Crochet Weaver** を有効化してください。

## リリース手順

1. `manifest.json` と `package.json` を同じ SemVer バージョンに更新します。
2. `versions.json` を更新し、プラグインバージョンが必要な最小 Obsidian バージョンに対応するようにします。
3. `npm test`、`npm run build`、`npm run lint` を実行します。
4. manifest のバージョンと完全に一致する（先頭に `v` を付けない）Git タグを作成します。
5. `manifest.json`、`main.js`、`styles.css` をリリースアセットとして添付した GitHub Release を公開します。
